# MySQL Assignment 1 – DDL Commands & Constraints

## 📌 Project Overview
This assignment focuses on practising SQL Data Definition Language (DDL) commands and implementing database constraints using MySQL. It demonstrates how to create and manage databases and tables, modify table structures, and maintain data accuracy and integrity.

## 🎯 Objectives
- Create and manage databases and tables.
- Practise DDL commands such as `CREATE`, `ALTER`, `RENAME`, `TRUNCATE`, and `DROP`.
- Apply constraints to maintain data integrity.
- Insert and manage department, location, and employee records.
- Establish relationships between tables using foreign keys.

## 🛠️ Tools Used
- **Database:** MySQL
- **IDE:** MySQL Workbench
- **Language:** SQL

## 📚 Topics Covered

### 1. DDL Commands
- `CREATE DATABASE` – Create a database.
- `CREATE TABLE` – Create tables.
- `ALTER TABLE` – Add, modify, or remove columns.
- `RENAME TABLE` – Rename tables.
- `TRUNCATE TABLE` – Remove all records from a table.
- `DROP TABLE` / `DROP DATABASE` – Delete tables or databases.

### 2. SQL Constraints
- **PRIMARY KEY:** Uniquely identifies each employee or department.
- **UNIQUE:** Prevents duplicate values.
- **NOT NULL:** Ensures required fields contain values.
- **CHECK:** Validates values against specified conditions, such as gender being M or F and age being at least 18.
- **DEFAULT:** Supplies a default value, such as the current date.
- **FOREIGN KEY:** Establishes relationships between Employees, Departments, and Location tables.

## 🗂️ Database Structure
The assignment uses three main tables:

- **Departments:** Stores department IDs and department names.
- **Location:** Stores location IDs and location names.
- **Employees:** Stores employee details, including employee ID, name, gender, age, date of joining, designation, department ID, location ID, salary, and email.

- Practised inserting records and troubleshooting SQL errors.
- Gained hands-on experience with MySQL Workbench.

Completed hands-on practice with DDL commands and SQL constraints to build and manage a relational database.
